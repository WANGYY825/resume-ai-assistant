# AI 简历自动填写助手 - 使用指南

## 一、安装与配置

### 1.1 安装插件
1. 克隆或下载本项目
2. 打开 Chrome 浏览器，访问 `chrome://extensions`
3. 开启右上角的「**开发者模式**」
4. 点击「**加载已解压的扩展程序**」
5. 选择项目中的 `extension/` 目录

### 1.2 配置 API
1. 右键点击浏览器扩展图标，选择「**选项**」
2. 在打开的页面右上角点击「**⚙ API 设置**」
3. 填入你的 Anthropic API Key（从 [console.anthropic.com](https://console.anthropic.com/) 获取）
4. 代理地址可选填（留空使用官方地址）
5. 点击「**保存**」

## 二、录入个人信息

### 2.1 方式一：上传简历文件 📄（推荐）
1. 在插件选项页右上角点击「**📄 上传简历**」
2. 选择你的简历文件（支持 `.pdf` 或 `.docx` 格式）
3. 点击「**开始解析**」
4. 等待 5-15 秒，AI 将自动提取信息并填入各字段
5. 可在左侧导航切换不同分类查看提取结果

**优点**：
- 快速批量导入，无需手动输入
- 支持复杂排版的简历文档
- 自动识别教育、工作、项目经历

### 2.2 方式二：粘贴文本解析 ✦
1. 复制简历的纯文本内容（可以是 Word、PDF 或网页上的文本）
2. 点击「**✦ 粘贴文本解析**」
3. 粘贴到文本框中
4. 点击「**开始解析**」
5. AI 自动提取关键信息并填入

**适用场景**：
- 从招聘网站或简历平台复制文本
- 快速更新部分信息
- 无法上传文件时的备选方案

### 2.3 方式三：手动填写 ✍️
1. 点击左侧导航切换到不同分类
   - 基本信息
   - 求职意向
   - 教育经历
   - 工作/实习经历
   - 项目经历
   - 技能与特长
   - 自定义字段
2. 逐项填写或修改
3. 点击「**保存**」按钮

## 三、版本管理

### 3.1 创建新版本
1. 点击左上角的「**+ 新版本**」按钮
2. 输入版本名称（如：技术岗、产品岗、国央企、互联网等）
3. 新版本会自动切换为当前编辑版本

### 3.2 切换版本
- 点击版本选择下拉框，选择要使用的简历版本

### 3.3 删除版本
- 点击「**删除版本**」按钮，确认后删除当前选中的版本

**提示**：不同岗位类型可使用不同版本简历，投递时灵活切换

## 四、自动填写招聘表单

### 4.1 基本使用
1. 打开招聘网站（如智联、BOSS、拉勾等）的职位申请页面
2. 点击浏览器工具栏的插件图标
3. 选择要使用的「**简历版本**」
4. （可选）选择「**指定填写内容**」
   - 如果某个经历段落有多条，可以指定填写第几条
5. 点击「**扫描并自动填写**」
6. 等待 5-15 秒，表单字段会自动填入
7. **人工检查**填写结果（高亮显示的字段）
8. 确认无误后手动提交表单

### 4.2 注意事项
- 验证码、密码等安全字段 AI 不会自动填写
- 填写完成后请**务必人工审核**，最终决策权在你
- 部分网站可能有反爬机制，填写失败属正常现象
- 如遇问题可刷新页面重试

## 五、常见问题

### Q1: 上传的简历为什么解析不完整？
**A**: 可能原因：
- PDF 是扫描版或图片格式（需要文字可选中的 PDF）
- 简历排版过于复杂，建议补充使用「粘贴文本解析」
- 简历内容不完整，手动补充缺失字段

### Q2: API Key 如何获取？
**A**: 
1. 访问 [console.anthropic.com](https://console.anthropic.com/)
2. 注册/登录账号
3. 创建 API Key 并复制
4. 在插件选项页的「API 设置」中填入

### Q3: 数据会上传到服务器吗？
**A**: 不会。所有个人信息都存储在浏览器本地 `chrome.storage.local`，除了调用 Claude API 进行文本解析外，不会上传任何服务器。

### Q4: 为什么有的表单字段没有填写？
**A**: 可能原因：
- 该字段在你的简历中没有对应信息
- AI 语义匹配失败（字段名称过于特殊）
- 该字段类型不支持自动填写（如上传文件、验证码等）

### Q5: 可以同时维护多份简历吗？
**A**: 可以。通过版本管理功能，可以创建多个版本（如校招版、社招版、外企版等），投递时切换即可。

## 六、高级技巧

### 6.1 自定义字段
如果招聘表单有特殊字段（如政治面貌、户籍等），可以在「自定义字段」分类中添加键值对。

### 6.2 指定填写段落
工作经历或项目经历有多条时，可以在弹窗中选择「指定填写内容」，避免重复填写相同经历。

### 6.3 API 代理设置
如果无法访问官方 API，可以在「API 设置」中填入代理地址（需支持 Anthropic API 接口）。

## 七、隐私与安全

- ✅ 个人信息本地存储，不上传第三方服务器
- ✅ API Key 仅用于调用 Claude 进行文本解析
- ✅ 不会自动填写密码、验证码等安全字段
- ⚠️ 请勿在不安全的设备上使用
- ⚠️ 建议定期更换 API Key
