# 📋 从表单导入 - 使用指南

## 功能简介

「从表单导入」功能可以将你在招聘网站已经填写过的表单内容批量导入到个人信息库，避免重复录入。

### 适用场景

✅ **已填写完整的招聘表单**
- 中国电信校园招聘
- 中国移动/联通招聘
- 国家电网、南方电网
- 智联招聘、前程无忧
- BOSS直聘、拉勾网
- 各企业官网招聘系统

✅ **需要复用的数据**
- 紧急联系人信息
- 是否有亲属在职
- 内推码
- 是否接受调剂
- 户口所在地、籍贯
- 政治面貌、民族
- 其他特殊字段

---

## 使用步骤

### 第一步：复制招聘表单内容

1. 打开你已经填写完成的招聘表单页面
2. **Ctrl+A**（全选页面内容）
3. **Ctrl+C**（复制）

> 💡 提示：建议在**填写完成但未提交**的状态下复制，这样可以保留所有填写的内容

### 第二步：打开导入功能

1. 打开浏览器，点击插件图标
2. 右键 → **选项**（或直接点击插件图标后选择「管理简历」）
3. 在个人信息库页面右上角点击 **「📋 从表单导入」**

### 第三步：粘贴并导入

1. 在弹出的文本框中 **Ctrl+V** 粘贴刚才复制的内容
2. 点击 **「开始导入」**
3. 等待 5-15 秒，AI 会自动解析内容
4. 看到 **「✓ 导入成功，已合并到当前简历版本（已自动去重）」** 提示
5. 弹窗自动关闭，页面刷新显示导入的数据

### 第四步：检查和补充

1. 切换左侧导航，查看各分类数据是否正确导入
2. 检查「自定义字段」分类，查看特殊字段是否正确保存
3. 如有缺失或错误，可手动修改

## 智能去重机制

系统会自动检测并避免重复添加相同的经历：

### 教育经历去重规则
- **相同学校 + 相同专业** → 视为重复，跳过

### 工作/实习经历去重规则
- **相同公司 + 相同职位** → 视为重复，跳过

### 项目经历去重规则
- **相同项目名称** → 视为重复，跳过

### 基本信息/技能/自定义字段
- **直接覆盖更新**，保留最新值

## 常见问题

### Q1: 导入后数据不完整怎么办？

**可能原因**：
1. 复制的内容不完整（未全选）
2. 表单有部分字段未填写
3. AI 提取遗漏（较少见）

**解决方法**：
1. 返回招聘网站，重新 Ctrl+A 全选后复制
2. 检查「自定义字段」分类，部分信息可能在那里
3. 手动补充缺失字段

### Q2: 为什么有些字段没有导入？

系统会**过滤**以下内容：
- 值为「请选择」的字段
- 值为「未选择任何文件」的字段
- 空白字段
- 页面导航和按钮文本

### Q3: 导入的数据会覆盖原有数据吗？

**分情况**：
- **基本信息/求职意向/技能**：直接更新覆盖
- **教育/工作/项目经历**：自动去重后追加，不会覆盖现有记录
- **自定义字段**：直接更新覆盖

> 💡 建议在导入前创建新的简历版本，避免误覆盖重要数据

### Q4: 可以导入多个招聘表单吗？

可以！按以下步骤操作：
1. 导入第一个表单（如中国电信）
2. 导入第二个表单（如中国移动）
3. 系统会自动合并数据，去重后保留所有信息

### Q5: 导入失败怎么办？

**错误提示「未提取到有效数据」**：
- 检查粘贴的内容是否包含实际填写的数据
- 确认不是空白页面或仅包含表单标题
- 尝试只复制表单主体部分（不含页眉页脚）

**错误提示「解析失败，请检查内容或 API 配置」**：
- 检查 API Key 是否正确配置
- 检查网络连接是否正常
- 稍后重试

## 使用技巧

### 技巧 1: 先导入再补充
1. 使用「从表单导入」快速导入 80% 的数据
2. 使用「上传简历」补充详细的项目描述
3. 手动修改优化特定字段

### 技巧 2: 创建多个版本
1. 导入中国电信表单 → 保存为「国企版」
2. 导入互联网公司表单 → 保存为「互联网版」
3. 投递时选择对应版本

### 技巧 3: 定期更新
每次填写新的招聘表单后：
1. 立即导入到信息库
2. 这样下次填表就可以直接复用
3. 形成正向循环，越用越方便

### 技巧 4: 善用自定义字段
导入后检查「自定义字段」分类，会发现很多特殊字段已自动保存：
- 紧急联系人信息
- 是否有亲属在职
- 内推码
- 政治面貌、民族

这些字段下次填表时会自动匹配填写！

## 与其他功能对比

| 功能 | 适用场景 | 优点 | 缺点 |
|------|----------|------|------|
| **📋 从表单导入** | 已填写的招聘表单 | 快速复用，包含特殊字段 | 需要先有填写好的表单 |
| **📄 上传简历** | 有 PDF/Word 简历 | 格式化文档，信息完整 | 不包含特殊字段 |
| **✦ 粘贴文本** | 纯文本简历内容 | 灵活方便 | 需要手动复制文本 |
| **✍️ 手动填写** | 精确控制每个字段 | 最准确 | 最耗时 |

**最佳实践**：组合使用
1. 第一次：上传简历 + 手动补充
2. 第一次填表后：从表单导入（保存特殊字段）
3. 后续：直接使用保存的数据自动填写
