# 页面提取功能使用指南

## 功能概述

「从页面提取信息」功能允许你从已填写好的招聘网站表单中自动提取个人简历信息，并保存到你的简历系统中，方便后续在其他招聘平台复用这些数据。

### 适用场景

- 已经在某个招聘平台填写过完整简历
- 想要将这些信息快速导入到本插件的简历库
- 避免重复手动录入相同信息

---

## 使用步骤

### 1. 打开已填写的表单页面

在浏览器中打开你已经填写过简历信息的招聘网站页面（例如 Boss直聘、智联招聘、前程无忧等）。

**注意：** 页面上的表单字段必须已经填写了内容，空白表单无法提取信息。

### 2. 点击插件图标

点击浏览器右上角的 **AI 简历填写助手** 图标，打开插件弹窗。

### 3. 点击「从页面提取信息」按钮

在弹窗中找到绿色的 **「从页面提取信息」** 按钮（位于「扫描并自动填写」按钮下方），点击它。

### 4. 等待提取完成

- 插件会扫描当前页面所有已填写的表单字段
- 调用 AI 识别字段的语义（姓名、手机、邮箱、工作经历、项目经历等）
- 将信息结构化并保存到简历系统

整个过程大约需要 **10-20 秒**。

### 5. 查看提取结果

提取完成后会弹出提示：

```
提取成功！

已保存到简历版本: 页面提取_2026-09-07 14:30

提取字段数: 28

请在插件设置页查看和编辑。
```

### 6. 编辑和完善信息

1. 右键点击插件图标 → **选项**，打开简历管理页
2. 在左上角的版本选择下拉框中，选择刚才提取的版本（名称格式：`页面提取_日期时间`）
3. 检查提取的信息是否准确，必要时手动修正
4. 保存后即可在填写其他平台表单时使用

## 支持的字段类型

AI 会自动识别以下类型的字段：

### 基本信息
- 姓名
- 手机号码
- 电子邮箱
- 所在城市
- LinkedIn / GitHub 主页

### 教育经历
- 学校名称
- 学位（本科/硕士/博士）
- 专业
- 入学/毕业时间

### 工作经历
- 公司名称
- 职位
- 入职/离职时间
- 工作内容描述

### 项目经历
- 项目名称
- 项目描述
- 使用的技术栈

### 技能
- 编程语言
- 技术框架
- 工具软件

## 注意事项

### 会跳过的字段

以下字段会被自动跳过，不会提取：

- 验证码
- 密码
- 手机验证码
- 推荐码/邀请码
- 协议勾选框

### 提取准确性

- **标题识别**：AI 会根据字段的标签（label）、name 属性、placeholder 提示文字等信息判断字段含义
- **内容匹配**：会将填写的内容与简历字段进行语义匹配
- **建议检查**：提取后建议人工检查一遍，确保信息正确

### 多页表单

如果表单分布在多个页面（如分步填写），需要：

1. 打开第一页，点击「从页面提取信息」
2. 进入下一页，再次点击提取
3. 插件会创建两个版本，可在设置页手动合并

## 常见问题

### Q1: 提示「未找到已填写的字段」

**原因：** 当前页面没有已填写内容的表单字段。

**解决：**
- 确保页面上有带值的输入框、下拉框或文本框
- 刷新页面后重试
- 检查是否需要先登录才能看到表单

### Q2: 提取的信息不完整

**原因：** 某些字段可能被网站隐藏或使用了非标准的表单组件。

**解决：**
- 在插件设置页手动补充缺失信息
- 或者使用「上传简历」功能重新解析 PDF/Word 简历

### Q3: 提取后信息错位（如工作经历混乱）

**原因：** AI 在识别多段经历时可能出现混淆。

**解决：**
- 在设置页手动调整各段经历的顺序和内容
- 删除错误条目，重新添加

### Q4: 想要覆盖已有版本而不是新建

当前版本会自动创建新的简历版本（命名为 `页面提取_时间戳`）。如果想替换现有版本：

1. 进入插件设置页
2. 选择要替换的版本
3. 手动复制粘贴提取版本的内容
4. 删除提取版本

## 与其他功能的配合使用

### 结合「上传简历」功能

1. 先上传 PDF/Word 简历，自动提取基本信息
2. 再使用「页面提取」补充在某些平台额外填写的内容（如项目职责细节）
3. 在设置页合并两个版本的优点

### 结合「扫描并自动填写」功能

1. 从 A 平台提取信息 → 生成简历版本 V1
2. 打开 B 平台的空白表单
3. 选择版本 V1 → 点击「扫描并自动填写」
4. 实现跨平台简历复用

## 技术原理

1. **前端扫描**：content.js 遍历页面所有可见的表单元素（input、textarea、select）
2. **提取已填值**：读取每个元素的 value、selectedIndex、checked 状态
3. **标签识别**：通过 label、aria-label、placeholder、name 等属性推断字段含义
4. **AI 解析**：调用 Claude API，将字段列表转换为结构化的 Profile 数据
5. **本地存储**：保存到 chrome.storage.local 的 profileVersions 对象
