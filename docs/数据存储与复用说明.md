# 数据存储与复用说明

本文档用通俗的语言解释"从页面提取"后，数据是如何存储的，以及下次如何复用。

---

## 📦 数据存储在哪里？

### 1. 存储位置
你的简历数据**完全存储在浏览器本地**，具体位置：

```
Chrome 浏览器 → 本地存储（chrome.storage.local）
```

**特点**：
- ✅ 不会上传到任何服务器
- ✅ 只有你的浏览器能访问
- ✅ 即使卸载插件，数据也不会丢失（除非清除浏览器数据）
- ✅ 不同电脑的 Chrome 登录同一账号也不会同步（除非开启插件同步）

### 2. 数据结构（多版本管理）

就像你电脑里可以保存多份简历（"国企版.docx"、"外企版.docx"），插件也支持多版本：

```
简历系统
├── 默认版本
├── 国央企版本
├── 互联网版本
└── 页面提取_2026-09-07 16:30  ← 从网页提取的新版本
```

## 🔄 从页面提取后发生了什么？

### 第 1 步：扫描网页
```
你点击「从页面提取信息」
    ↓
插件扫描当前网页的所有表单字段
    ↓
找到所有已填写的内容
```

**示例**：假设你在 Boss直聘 填写了简历
```
找到：
- 姓名框：张三
- 手机框：13800138000
- 学历下拉框：硕士研究生（已选中）
- 公司框：字节跳动
- 项目描述框：负责开发飞书文档编辑器...
```

### 第 2 步：AI 理解内容
```
原始字段（网页上的）  →  AI 语义识别  →  标准简历格式
```

**示例**：
```
网页字段名            AI 识别为          保存到
realname         →   姓名             →   基本信息.姓名
mobile_phone     →   手机号           →   基本信息.手机
education_level  →   最高学历         →   教育经历.学位
company_name     →   公司名称         →   工作经历.公司
project_content  →   项目描述         →   项目经历.描述
```

**为什么需要 AI？**
- 不同网站的字段名不一样：
  - 有的叫 `name`，有的叫 `realname`，有的叫 `user_name`
  - AI 通过语义理解，知道它们都是"姓名"
  - 下拉框的选项文字（"硕士研究生"）也能正确识别

### 第 3 步：保存为新版本
```
AI 识别完成
    ↓
自动创建新版本：页面提取_2026-09-07 16:30
    ↓
保存到浏览器本地存储
    ↓
弹出提示：提取成功！
```

**版本命名规则**：
- 格式：`页面提取_年-月-日 时:分`
- 示例：`页面提取_2026-09-07 16:30`
- 便于区分不同时间提取的数据

### 第 4 步：查看和编辑
```
右键插件图标 → 选项 → 打开设置页
    ↓
左上角版本下拉框 → 选择「页面提取_2026-09-07 16:30」
    ↓
查看提取的数据，可以手动修改和完善
    ↓
点击「保存」→ 数据更新
```

## ✍️ 下次如何复用数据？

### 场景：填写新的招聘网站

**第 1 步：打开新网站**
```
打开智联招聘/前程无忧/拉勾网...的简历填写页面
```

**第 2 步：选择版本**
```
点击浏览器右上角的插件图标
    ↓
在弹窗中选择要使用的简历版本
    ↓
比如选择「页面提取_2026-09-07 16:30」（刚从 Boss直聘 提取的）
```

**第 3 步：自动填写**
```
点击「扫描并自动填写」按钮
    ↓
插件扫描当前网页的空白表单
    ↓
AI 识别哪个字段应该填什么内容
    ↓
自动填入对应信息
    ↓
已填写的字段会高亮显示（绿色背景）
```

**第 4 步：人工确认**
```
检查自动填写的内容是否正确
    ↓
手动调整不对的地方
    ↓
提交表单
```

## 🤖 AI 是怎么匹配字段的？

### 示例 1：基本信息字段

**Boss直聘 的字段**：
```html
<input name="realname" placeholder="请输入真实姓名">
<input name="mobile" placeholder="请输入手机号">
<select name="edu_level">
  <option>本科</option>
  <option>硕士研究生</option>  ← 你选了这个
</select>
```

**智联招聘 的字段**（字段名不同）：
```html
<input name="user_name" placeholder="姓名">
<input name="phone_number" placeholder="联系电话">
<select name="education">
  <option>大学本科</option>
  <option>硕士</option>  ← AI 知道要选这个
</select>
```

**AI 的匹配逻辑**：
```
1. 从简历数据中读取：姓名 = "张三"
2. 看到智联招聘有个字段 placeholder="姓名"
3. AI 理解：这个字段要填姓名
4. 自动填入："张三"

1. 从简历数据中读取：学历 = "硕士研究生"
2. 看到智联招聘有个下拉框，选项包括"硕士"
3. AI 理解："硕士研究生" ≈ "硕士"
4. 自动选中："硕士"
```

### 示例 2：工作经历字段

**从 Boss直聘 提取的数据**：
```javascript
工作经历: [
  {
    公司: "字节跳动",
    职位: "前端工程师",
    开始时间: "2023-07",
    结束时间: "至今",
    描述: "负责飞书文档编辑器开发，使用 React + TypeScript..."
  }
]
```

**智联招聘 的字段**：
```html
<input placeholder="公司名称">
<input placeholder="职位名称">
<input placeholder="开始时间">
<input placeholder="结束时间">
<textarea placeholder="工作内容描述"></textarea>
```

**AI 的匹配逻辑**：
```
1. AI 识别：智联招聘要填"工作经历"
2. 从简历数据中读取第一条工作经历
3. 按字段一一对应填入：
   - 公司名称 ← "字节跳动"
   - 职位名称 ← "前端工程师"
   - 开始时间 ← "2023-07"
   - 结束时间 ← "至今"
   - 工作内容 ← "负责飞书文档编辑器开发..."
```

**如果有多段工作经历怎么办？**
```
在插件弹窗中，你可以选择「指定填写段落」：
- 填写第 1 段工作经历
- 填写第 2 段工作经历
- ...

比如：投递初级岗位时填第 2 段实习经历，投递高级岗位时填第 1 段正式工作经历
```

## 🔐 数据安全性

### Q1：我的简历数据会被上传吗？
**答**：不会。数据完全存储在**你的浏览器本地**，不会上传到任何服务器。

### Q2：那 AI 识别时不是要发送给 Claude API 吗？
**答**：是的，但只是发送给 Claude API 进行识别，并不会存储在 Anthropic 的服务器上。
- Anthropic 官方承诺：API 调用的数据不会用于训练模型
- 你可以查看 Anthropic 的隐私政策：https://www.anthropic.com/privacy

### Q3：换电脑后数据还在吗？
**答**：不在。数据存储在浏览器本地，换电脑需要重新录入。

**解决方案**：
1. 导出数据：在设置页手动复制简历内容
2. 在新电脑上粘贴导入
3. 或者重新使用「从页面提取」功能

### Q4：清除浏览器数据会丢失简历吗？
**答**：是的。如果你在 Chrome 设置中清除了"网站数据"或"Cookie 和其他网站数据"，插件的数据也会被清除。

**建议**：
- 定期在设置页查看简历内容
- 重要信息可以复制保存到本地文件

## 🎯 总结

### 数据存储
- **位置**：浏览器本地（chrome.storage.local）
- **格式**：多版本管理，每个版本是一份完整简历
- **安全**：完全本地，不上传服务器

### 数据提取
- **方式**：扫描网页已填字段 + AI 语义识别
- **结果**：自动创建新版本（格式：`页面提取_时间戳`）
- **操作**：点击「从页面提取信息」一键完成

### 数据复用
- **场景**：填写新的招聘网站表单
- **方式**：选择版本 + 点击「扫描并自动填写」
- **智能**：AI 语义匹配，自动识别字段对应关系
- **安全**：人工确认后再提交

### 核心优势
✅ **省时**：填写一次，复用无数次  
✅ **智能**：AI 自动识别字段，无需手动配置  
✅ **灵活**：多版本管理，不同场景切换自如  
✅ **安全**：本地存储，隐私有保障  
✅ **双向**：既能导出（自动填写），也能导入（页面提取）
